# خادم الويب Cherokee

هذا المشروع يحتوي على المصدر المفتوح لخادم الويب **Cherokee 1.2.103**، ومعه صفحة عربية لعرض مؤشرات النظام.

## تجربة لوحة المراقبة

تعمل لوحة المراقبة على Linux، ولا تحتاج إلى تثبيت حزم Python إضافية:

```sh
python3 monitor_server.py
```

افتح [http://localhost:8000](http://localhost:8000) في المتصفح. لإيقاف الخدمة، اضغط `Ctrl+C` في الطرفية.

تعرض اللوحة استخدام الذاكرة والقرص، واتصالاً خارجياً تجريبياً، وحالة واجهات الشبكة، ومنافذ TCP وUDP المفتوحة. تقرأ القياسات من الجهاز الذي يشغّل `monitor_server.py`؛ لذلك فهي لا تمثل خادماً بعيداً.

## ملاحظات الأمان

- خدمة المراقبة مربوطة بعنوان الجهاز المحلي فقط، وليست واجهة عامة للإنترنت.
- تنبيه «المنافذ المشبوهة» يقارن المنافذ المفتوحة بقائمة قصيرة من المنافذ الشائعة. عدم ظهور تنبيه لا يثبت خلو الجهاز من باب خلفي أو برمجية ضارة.
- لا تفتح المنفذ `8000` للعامة ولا تزل قيد الوصول المحلي.

## بناء خادم Cherokee

لبناء الخادم من المصدر، تحتاج إلى أدوات البناء الأساسية. على Ubuntu أو Debian:

```sh
sudo apt-get update
sudo apt-get install autoconf automake libtool
cd webserver-1.2.103
./autogen.sh
make
```

توجد تفاصيل إضافية ومتطلبات بناء المنصات المختلفة في [دليل Cherokee الأصلي](webserver-1.2.103/README.rst).
